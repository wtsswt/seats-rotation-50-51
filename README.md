# 教室座位轮换

按固定置换规则批量生成轮换座位表，支持两套教室布局。以一张 Excel 工作表为初始状态，逐轮复制并置换，替代人工重排。

## 文件

| 文件 | 说明 |
| --- | --- |
| `rotate_51.py` | 51 座布局（7 列 × 8 排）轮换脚本 |
| `seats_51.xlsx` | 对应示例表，51 个座位、实坐 50 人 |
| `rotate_50.py` | 50 座布局（8 列 × 7 排）轮换脚本 |
| `seats_50.xlsx` | 对应示例表，50 个座位、实坐 50 人 |
| `requirements.txt` | `openpyxl>=3.1` |
| `LICENSE` | MIT |

示例表已把所有姓名替换为「学生01」–「学生50」，仅含 `Sheet1`，可直接运行。轮换逻辑与姓名无关。

## 运行

脚本按相对路径读取同目录的示例表，须在仓库根目录执行：

```bash
pip install -r requirements.txt
python3 rotate_51.py    # 或 python3 rotate_50.py
```

以 `Sheet{a}` 为起点，每轮复制上一轮并置换，依次生成 `Sheet{a+1}` 至 `Sheet{a+n}`，工作表编号即轮次。处理完写回原文件。

参数是脚本内的常量，改后重跑生效：

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `input_file_path` | `seats_51.xlsx` / `seats_50.xlsx` | 读写的目标工作簿 |
| `a` | `1` | 起始工作表序号，工作簿中须已存在 `Sheet{a}` |
| `n` | `100` | 本轮生成的工作表数量 |

## 布局约定

两套表都是 A 列排号递减、**Excel 第 1 行对应最后一排**，第 1 排（靠门侧）落在最后一行。

- **51 座**：第 9 行为列号，B9:H9 对应列 1–7。座位区由 F1、G1 与 B2:H8 构成；示例表 H8 空置。第 11、12 行与 I 列作暂存区。
- **50 座**：第 8 行为列号，B8:I8 对应列 1–8。座位区由 G1、H1 与 B2:I7 构成，示例表全部就座。

轮换规则的实现见两个脚本：`rotate_51.py` 用一张 16 条「源区域 → 目标区域」的搬运指令表，按顺序执行且顺序不可调；`rotate_50.py` 用坐标计算一次性置换（列号 +1、行号 +1，越界回绕），三个角格走 `special_moves` 单独映射。

## 注意

1. 两个脚本都是**原地写回**，无撤销机制，运行前请备份。
2. `rotate_51.py` 不处理同名工作表：目标表名已存在时 `openpyxl` 会自动追加序号（如 `Sheet21`），因此不宜在已生成结果的工作簿上重复执行。
3. 两套变换均校验为 50 名学生的一一置换，无重复、无遗漏。`rotate_50.py` 周期 50 轮，默认 `n=100` 会使后 50 张与前 50 张重复；`rotate_51.py` 周期 336 轮。按实际需要设置 `n`。
4. `.gitignore` 默认忽略所有表格，仅放行两个示例表。请勿提交含真实姓名的座位表。
