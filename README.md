# 50/51 Seats Rotation

Rotate classroom seating charts in Excel — two fixed layouts (50/51 seats), 100 rounds per run.

两套互相独立的座位表轮换程序，分别对应两间不同教室的座位布局。都是高中做班级事务时写的：每周换座位，手动排既费时间又容易漏人，就改成用 Python 按 Excel 坐标批量生成。

仓库里的姓名已全部替换为「学生01」这类占位名，可以直接跑。

```
rotate_51.py    51 人的教室，7 列 × 8 排
seats_51.xlsx   对应的座位表
rotate_50.py    50 人的教室，8 列 × 7 排
seats_50.xlsx   对应的座位表
```

---

## 一、rotate_51.py · 51 人教室（7 列 × 8 排）

### 座位布局

Excel 里 **A 列是排号**（A1 是第 8 排，A8 是第 1 排，从上往下跌减），**第 9 行是列号**（B9~H9 对应列 1~7），A9 标着「门」。所以 **Excel 第 1 行是最后一排，第 8 行才是第一排**，门在第一排这一侧。

```
          列1    列2    列3    列4    列5    列6    列7
第8排      ·      ·      ·      ·     F1     G1      ·        ← Excel 第 1 行
第7排      B2     C2     D2     E2     F2     G2     H2
第6排      B3     C3     D3     E3     F3     G3     H3
第5排      B4     C4     D4     E4     F4     G4     H4
第4排      B5     C5     D5     E5     F5     G5     H5
第3排      B6     C6     D6     E6     F6     G6     H6
第2排      B7     C7     D7     E7     F7     G7     H7
第1排      B8     C8     D8     E8     F8     G8      ·        ← 门（A9）
```

- 第一排 7 个座位（列 1~7），其中列 7 的 **H8 目前空着**，实际坐 6 人
- 第二至第七排每排 7 人
- 第八排只有列 5、列 6 两个座位（F1、G1）
- 合计 **51 个座位**，当前表里坐了 50 人

### 程序逻辑

用的是一张写死的**搬运指令表**，共 16 条，每条是「源区域 → 目标区域」，两个区域按行优先一一对应，源格内容搬走后清空：

```python
operations = [
    ('C1', 'H8'), ('G8', 'F11'), ('F8', 'G11'), ('H8', 'B12'),
    ('B8:E8', 'C12:F12'),
    ('H2:H7', 'I2:I7'), ('G1:G7', 'H2:H8'), ('F1:F7', 'G2:G8'),
    ('E2:E7', 'F3:F8'), ('D2:D7', 'E3:E8'), ('C2:C7', 'D3:D8'),
    ('B2:B7', 'C3:C8'), ('I2:I7', 'B3:B8'),
    ('B12:F12', 'B2:F2'), ('F11:G11', 'F1:G1'), ('H8', 'B2'),
]
```

这套指令是靠顺序串起来的：第一排先搬到第 11、12 行暂存，再绕回第 2 行，最后第八排那两个座位补位。**因此指令的先后顺序不能打乱**，改坐标时也要连着前后几条一起看。第 10~12 行在这里只是临时中转，不坐人。

### 运行

```bash
python3 rotate_51.py
```

脚本会**原地修改** `seats_51.xlsx`：以 `Sheet{a}` 为起点，连续推出 `Sheet{a+1}` 到 `Sheet{a+n}`。文件开头的 `a`（起始表号）和 `n`（生成张数）默认是 1 和 100。

## 二、rotate_50.py · 50 人教室（8 列 × 7 排）

### 座位布局

同样 **A 列是排号**（A1 是第 7 排，A7 是第 1 排），**第 8 行是列号**（B8~I8 对应列 1~8），A8 标着「门」。**Excel 第 1 行仍是最后一排，第 7 行是第一排。**

```
          列1    列2    列3    列4    列5    列6    列7    列8
第7排      ·      ·      ·      ·      ·     G1     H1      ·     ← Excel 第 1 行（最后一排）
第6排      B2     C2     D2     E2     F2     G2     H2     I2
第5排      B3     C3     D3     E3     F3     G3     H3     I3
第4排      B4     C4     D4     E4     F4     G4     H4     I4
第3排      B5     C5     D5     E5     F5     G5     H5     I5
第2排      B6     C6     D6     E6     F6     G6     H6     I6
第1排      B7     C7     D7     E7     F7     G7     H7     I7     ← 门（A8）
```

- 第一至第六排每排 8 人
- **第七排（最后一排）只有列 6、列 7 两个座位**（G1、H1），不在讲台侧
- 合计 **50 个座位**

### 程序逻辑

走的是**对角线滑动**：`B2:I7` 这 48 个座位里，每人右移一列、后移一排，越过边界就绕回起始列 / 起始行。

最后一排那两个座位（G1、H1）不在 `B2:I7` 矩形里，所以单独处理：

- `all_seats` 里额外补上 `G1`、`H1`，让它们参与位移
- `special_moves` 把最后三格 `F7`、`G7`、`H7` 的人指定到 `G2`、`H1`、`G1`

每生成一张新表，都是在**上一张**的基础上再滑一次，所以 Sheet n 就是第 n 轮的座位。

### 运行

```bash
python3 rotate_50.py
```

同样是原地修改 `seats_50.xlsx`，参数 `a`、`n` 的用法与上面一致。
