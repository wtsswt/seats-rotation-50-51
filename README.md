# 50/51 Seats Rotation

Batch generation of rotated classroom seating charts for two fixed Excel layouts (50 / 51 seats).

## 项目概述

本仓库提供两套相互独立的座位轮换脚本，分别对应两种固定教室布局。每套脚本以一张 Excel 工作表为初始状态，按既定置换规则逐轮生成新工作表，用于周期性调整班级座位，替代人工重排。

仓库随附的示例表已将学生姓名统一替换为“学生01”至“学生50”的占位名，仅含 `Sheet1`，可直接运行。轮换逻辑与具体姓名无关，替换为学生名单后同样适用。

## 安装与运行

依赖 Python 3 与 `openpyxl`。脚本按相对路径读取同目录下的示例表，须在项目根目录执行：

```bash
pip install -r requirements.txt
python3 rotate_51.py    # 或 python3 rotate_50.py
```

脚本以 `Sheet{a}` 为起点，每轮复制上一轮工作表并执行置换，依次生成 `Sheet{a+1}` 至 `Sheet{a+n}`；工作表编号即轮次。处理完成后写回原 `.xlsx` 文件，控制台输出“已完成”。

参数以脚本内常量形式提供，修改后重新运行生效：

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `input_file_path` | `seats_51.xlsx` / `seats_50.xlsx` | 读写的目标工作簿 |
| `a` | `1` | 起始工作表序号，工作簿中须已存在 `Sheet{a}` |
| `n` | `100` | 本轮生成的工作表数量 |

> **注意**：两个脚本均为**原地写回**，不提供撤销机制。运行前请备份工作簿。

## 一、51 座布局（`rotate_51.py`）

### 数据格式

- A 列为排号，自 A1（第 8 排）至 A8（第 1 排）递减；第 9 行为列号，B9:H9 对应列 1–7，A9 标记“门”。
- 因此 **Excel 第 1 行对应最后一排，第 8 行对应第一排（靠门侧）**。
- 座位区由 F1、G1 与 B2:H8 构成，共 51 格；示例表中 H8 空置，实际就座 50 人。
- 第 11、12 行及 I 列在运算中作为暂存区，不参与排座。

```
          列1    列2    列3    列4    列5    列6    列7
第8排      ·      ·      ·      ·     F1     G1      ·     ← Excel 第 1 行（最后一排）
第7排      B2     C2     D2     E2     F2     G2     H2
第6排      B3     C3     D3     E3     F3     G3     H3
第5排      B4     C4     D4     E4     F4     G4     H4
第4排      B5     C5     D5     E5     F5     G5     H5
第3排      B6     C6     D6     E6     F6     G6     H6
第2排      B7     C7     D7     E7     F7     G7     H7
第1排      B8     C8     D8     E8     F8     G8      ·     ← Excel 第 8 行（靠门侧）
```

### 轮换规则

轮换由固定的搬运指令表 `operations` 定义，共 16 条，每条为“源区域 → 目标区域”。区域按行优先顺序逐格对应，写入目标后源单元格置空：

```python
operations = [
    ('C1', 'H8'), ('G8', 'F11'), ('F8', 'G11'), ('H8', 'B12'),
    ('B8:E8', 'C12:F12'),
    ('H2:H7', 'I2:I7'), ('G1:G7', 'H2:H8'), ('F1:F7', 'G2:G8'),
    ('E2:E7', 'F3:F8'), ('D2:D7', 'E3:E8'), ('C2:C7', 'D3:D8'),
    ('B2:B7', 'C3:C8'), ('I2:I7', 'B3:B8'),
    ('B12:F12', 'B2:F2'), ('F11:G11', 'F1:G1'), ('H8', 'B2'),
]
```

各条指令存在数据依赖，须按列表顺序执行：前 5 条将第一排与 C1 的内容移至第 11、12 行暂存，中间 8 条借助 I 列完成 B:H 各列的错位平移，最后 3 条将暂存内容写回第 2 行、F1:G1 与 B2，形成一轮闭环。**指令顺序不可调整**；修改任一坐标时须同步核对前后相关指令。

## 二、50 座布局（`rotate_50.py`）

### 数据格式

- A 列为排号，自 A1（第 7 排）至 A7（第 1 排）递减；第 8 行为列号，B8:I8 对应列 1–8，A8 标记“门”。
- **Excel 第 1 行对应最后一排，第 7 行对应第一排（靠门侧）**。
- 座位区由 G1、H1 与 B2:I7 构成，共 50 格，示例表中全部就座。

```
          列1    列2    列3    列4    列5    列6    列7    列8
第7排      ·      ·      ·      ·      ·     G1     H1      ·     ← Excel 第 1 行（最后一排）
第6排      B2     C2     D2     E2     F2     G2     H2     I2
第5排      B3     C3     D3     E3     F3     G3     H3     I3
第4排      B4     C4     D4     E4     F4     G4     H4     I4
第3排      B5     C5     D5     E5     F5     G5     H5     I5
第2排      B6     C6     D6     E6     F6     G6     H6     I6
第1排      B7     C7     D7     E7     F7     G7     H7     I7     ← Excel 第 7 行（靠门侧）
```

### 轮换规则

`custom_rotate(ws)` 以坐标计算一次性置换：先读取全部座位的值，再清空所有目标格并统一写回，避免读写冲突。

- **常规位移**：B2:I7 中除 F7、G7、H7 外的 45 格，列号 +1、行号 +1；越过 I 列回绕至 B 列，越过第 7 行回绕至第 2 行。
- **补充座位**：G1、H1 不在矩形区域内，另行加入上述位移集合。
- **特殊映射**：`special_moves` 将 F7、G7、H7 分别指定至 G2、H1、G1。

每轮以上一轮工作表为输入，故 `Sheet{a+k}` 即第 k 轮结果。目标工作表若已存在，脚本会先将其删除再重建。

## 注意事项

1. 两个脚本均原地写回同名工作簿，运行前须备份；参数 `a`、`n`、`input_file_path` 需编辑脚本后重新运行。
2. `rotate_51.py` 不处理同名工作表：若目标表名已存在，`openpyxl` 会自动追加序号（如 `Sheet21`），因此不建议在已生成结果的工作簿上重复执行。
3. 经校验，两套变换均为 50 名学生在有效座位上的一一置换，无重复、无遗漏。在示例数据下，`rotate_50.py` 的置换周期为 50 轮，默认 `n=100` 会使后 50 张表与前 50 张重复；`rotate_51.py` 周期为 336 轮，默认 100 张不重复。建议按实际需要设置 `n`。
4. `.gitignore` 默认忽略所有表格文件，仅放行两个示例表；请勿将含真实姓名的座位表提交至仓库。
